# Hair Assets

Active hair files live in this directory and use paired layer names:

- `hairN-back.png` or `hairN-back.webp` renders behind the face/head and is used as the picker preview.
- `hairN-front.png` or `hairN-front.webp` renders above the face/head.
- One hairstyle card is created per `hairN`, not per layer.
- A hairstyle must have a back layer to appear in the picker.
- Export front and back layers from the same transparent frame.

Current uploaded set: `hair1` through `hair61`, each with `back` and `front` PNG layers.
