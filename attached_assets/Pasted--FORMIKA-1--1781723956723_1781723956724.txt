Внести правки в конструктор FORMIKA.

━━━━━━━━━━━━━━━━━━━━

1. РАЗДЕЛ "ФОН"

Сейчас текст "Индивидуальный фон" вылезает за пределы контейнера.

Исправить layout.

Раздел "Фон" должен быть вертикальным:

Сначала:

Белый фон
Входит в стоимость

Ниже:

Индивидуальный фон
от +5 €

Под ним текст:

Цена индивидуального фона может меняться в зависимости от сложности. Точная стоимость согласовывается в Telegram.

━━━━━━━━━━━━━━━━━━━━

Важно:

* текст не должен выходить за пределы карточки
* карточка должна расширяться по высоте
* длинный текст должен переноситься на новую строку
* не использовать одну узкую строку для всего текста

━━━━━━━━━━━━━━━━━━━━

2. СЕРДЕЧКИ НА ЗАДНИЙ ФОН — ВРАЩЕНИЕ

Сердечки должны быть draggable-элементами.

Добавить возможность вращать каждое сердечко на 360 градусов.

Пользователь должен иметь возможность:

* выбрать сердечко
* переместить его внутри рамки
* повернуть его на любой угол от 0 до 360 градусов

Добавить аккуратный маленький rotate-handle возле выбранного сердечка.

Не делать большой круг вокруг элемента.

━━━━━━━━━━━━━━━━━━━━

3. ВЫБРАННЫЙ ЭЛЕМЕНТ

Когда пользователь выбирает любой элемент в preview:

* персонажа
* питомца
* аксессуар
* сердечко

на нём должно появляться аккуратное оранжевое свечение.

Цвет свечения:

#FF6A00

Свечение должно быть мягким, красивым и премиальным.

━━━━━━━━━━━━━━━━━━━━

Не использовать:

* большой круг вокруг элемента
* грубую рамку
* синие стандартные браузерные выделения
* некрасивые handles

Нужно именно мягкое оранжевое свечение.

━━━━━━━━━━━━━━━━━━━━

4. ПРОБЛЕМА "ЗАЛИПАНИЯ" ПРИ ПЕРЕТАСКИВАНИИ

Сейчас после отпускания мышки элемент иногда продолжает как будто залипать.

Исправить drag behavior.

После mouseup / touchend:

* элемент должен сразу отпускаться
* dragging state должен сбрасываться
* курсор должен возвращаться в нормальное состояние
* элемент не должен двигаться дальше сам

━━━━━━━━━━━━━━━━━━━━

Добавить обработку:

* mouseup
* mouseleave
* touchend
* touchcancel

Чтобы элемент не залипал при перетаскивании.

━━━━━━━━━━━━━━━━━━━━

5. ОБЩЕЕ ПОВЕДЕНИЕ

Выделение элемента должно работать так:

* кликнул на элемент → появилось мягкое оранжевое свечение
* начал двигать → элемент двигается
* отпустил мышку → элемент остаётся на месте
* залипания нет
* можно выбрать другой элемент
* свечение переходит на новый выбранный элемент

━━━━━━━━━━━━━━━━━━━━

Главная цель:

Сделать перемещение сердечек и других элементов аккуратным, понятным и премиальным, без визуального мусора и без залипания.
