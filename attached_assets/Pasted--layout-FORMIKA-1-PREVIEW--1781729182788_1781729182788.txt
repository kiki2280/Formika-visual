Внести правки в layout конструктора FORMIKA.

━━━━━━━━━━━━━━━━━━━━

1. PREVIEW ДОЛЖЕН БЫТЬ ВИДЕН ПРИ ПРОКРУТКЕ

Сейчас блок "Настройки рамки" очень длинный, и когда пользователь прокручивает настройки вниз, preview уходит вверх и его не видно.

Нужно сделать preview sticky.

То есть блок preview должен оставаться видимым при прокрутке страницы.

Требования:

* preview должен фиксироваться внутри своей колонки
* при прокрутке настроек preview должен плавно оставаться рядом
* пользователь всегда должен видеть рамку, когда выбирает элементы
* sticky должен работать только на desktop

Использовать поведение:

position: sticky;
top: 100px;

━━━━━━━━━━━━━━━━━━━━

2. БЛОК "ВАШ ЗАКАЗ"

Сейчас блок "Ваш заказ" растягивается по высоте так же, как длинная колонка настроек рамки.

Это неправильно.

Нужно сделать блок "Ваш заказ" независимым по высоте.

Он не должен автоматически растягиваться до высоты левой колонки.

Требования:

* высота блока "Ваш заказ" должна зависеть только от его содержимого
* если в заказе мало позиций, блок должен быть компактным
* если добавляются новые позиции, блок постепенно растёт вниз
* не растягивать блок искусственно до высоты всего конструктора

━━━━━━━━━━━━━━━━━━━━

3. ВЕРСТКА ТРЁХ КОЛОНОК

Колонки должны работать независимо:

Левая колонка:
настройки рамки, может быть длинной

Центральная колонка:
sticky preview, всегда видно

Правая колонка:
"Ваш заказ", компактный блок по содержимому

━━━━━━━━━━━━━━━━━━━━

4. ТЕХНИЧЕСКОЕ ТРЕБОВАНИЕ

Проверить CSS для контейнера колонок.

Не использовать:

align-items: stretch

если из-за этого блок "Ваш заказ" растягивается.

Использовать:

align-items: flex-start

для колонок конструктора.

Для preview использовать:

position: sticky;
top: 100px;

Для блока "Ваш заказ" использовать:

height: auto;
align-self: flex-start;

━━━━━━━━━━━━━━━━━━━━

5. ГЛАВНАЯ ЦЕЛЬ

Когда пользователь прокручивает длинные настройки рамки:

* preview остаётся видимым
* пользователь сразу видит изменения
* блок "Ваш заказ" не растягивается пустым пространством
* интерфейс выглядит аккуратно и профессионально
