Внести правки в Home Page FORMIKA.

Не создавать новую страницу.

Все кнопки "Подробнее" должны открывать большое модальное окно поверх главной страницы.

Модальное окно должно быть в том же стиле:

* чёрный фон
* белый текст
* оранжевый #FF6A00
* мягкое свечение
* премиальные карточки
* скругление
* кнопка закрытия
* затемнение фона сайта

━━━━━━━━━━━━━━━━━━━━

1. НАШИ РАБОТЫ

В секции "Наши работы" карточки:

* Персональные
* Для пары
* Семейные
* Автомобили

При нажатии "Подробнее" открывать большое окно.

Внутри окна:

* заголовок категории
* короткое описание
* 4 примера работ
* кнопка "Заказать →"

Кнопка "Заказать →" ведёт на страницу конструктора.

━━━━━━━━━━━━━━━━━━━━

Тексты:

Персональные

Композиции для одного человека, хобби, профессии или особенного образа. Можно добавить имя, дату, питомца, аксессуары и подсветку.

Для пары

Подарок для годовщины, свадьбы, предложения или важного момента вдвоём. Можно добавить имена, дату, питомца и детали вашей истории.

Семейные

Тёплая композиция для семьи, детей, родителей и домашних питомцев. Хорошо подходит для семейных праздников и памятных подарков.

Автомобили

Композиция для автолюбителей. Можно добавить автомобиль, владельца, номер, дату и детали, связанные с машиной.

━━━━━━━━━━━━━━━━━━━━

2. ВАРИАНТЫ ПОДСВЕТКИ

В секции "Варианты подсветки" у каждой карточки добавить кнопку "Подробнее".

Карточки:

* LED-гирлянда
* LED RGB
* LED с облаками

При нажатии открывать большое модальное окно.

Внутри:

* название подсветки
* короткое описание
* 3–4 примера работ с этой подсветкой
* кнопка "Заказать →"

Тексты:

LED-гирлянда

Тёплый уютный свет с одним режимом свечения. Подходит для мягкой домашней атмосферы.

LED RGB

Яркая цветная подсветка. Подходит, если хочется более заметный эффект и возможность разных оттенков.

LED с облаками

Объёмный декоративный эффект с мягким рассеиванием света. Выглядит более необычно и ярко.

━━━━━━━━━━━━━━━━━━━━

3. ДРУГИЕ ТОВАРЫ FORMIKA

В секции "Другие товары FORMIKA" добавить "Подробнее" для:

* Готовые брелоки
* Кастомные фигурки

При нажатии открывать большое модальное окно.

Внутри:

* название товара
* короткое описание
* 3–4 примера
* кнопка "Заказать →"

Тексты:

Готовые брелоки

Готовые модели FORMIKA, которые можно заказать сразу. Подходят как небольшой подарок или дополнение к рамке.

Кастомные фигурки

Отдельные персональные фигурки без рамки и без брелока. Можно подобрать лицо, волосы, одежду и аксессуары.

━━━━━━━━━━━━━━━━━━━━

4. ПОВЕДЕНИЕ ОКНА

Модальное окно должно быть крупным:

Desktop:
70–80% ширины экрана.

Внутри примеры показывать сеткой:

2 сверху
2 снизу

Если примеров 3 — сделать 3 карточки в один ряд или аккуратную сетку.

При открытии модального окна карточка/секция может слегка увеличиваться.

Фон сайта позади затемнить и слегка размыть.

━━━━━━━━━━━━━━━━━━━━

5. ВАЖНО

Не делать отдельную страницу каталога.

Не уводить пользователя далеко с Home Page.

Все примеры показывать через модальные окна.

Главная цель:
клиент нажимает "Подробнее", видит 3–4 примера и сразу может перейти в конструктор через кнопку "Заказать →".
