1. КАСТОМНЫЙ БРЕЛОК — КОЛИЧЕСТВО

В разделе "Собрать свой брелок" добавить управление количеством.

Название блока:

Количество кастомных брелков

По умолчанию:

0

Формат:

[ - ] 0 [ + ]

━━━━━━━━━━━━━━━━━━━━

Логика:

* кнопка "+" увеличивает количество на 1
* кнопка "-" уменьшает количество на 1
* минимальное значение 0
* нельзя уйти ниже 0

━━━━━━━━━━━━━━━━━━━━

Цена:

1 кастомный брелок = 7 €

Расчёт:

0 шт = 0 €
1 шт = 7 €
2 шт = 14 €
3 шт = 21 €

Цена должна автоматически меняться от количества.

━━━━━━━━━━━━━━━━━━━━

2. ДОБАВИТЬ ЭТУ ЖЕ ФУНКЦИЮ ДЛЯ ГОТОВЫХ БРЕЛКОВ

В разделе "Готовые брелоки" добавить количество для каждого готового брелка отдельно.

Готовые брелоки:

* Чёрный Бэтмен
* Розовый Бэтмен
* Синяя акула
* Розовая акула

У каждого брелка должна быть своя настройка количества:

[ - ] 0 [ + ]

━━━━━━━━━━━━━━━━━━━━

Цена:

1 готовый брелок = 7 €

Пример:

Чёрный Бэтмен:
2 шт × 7 € = 14 €

Розовый Бэтмен:
0 шт = 0 €

Синяя акула:
1 шт × 7 € = 7 €

Розовая акула:
1 шт × 7 € = 7 €

Итого:
28 €

━━━━━━━━━━━━━━━━━━━━

3. ВАШ ЗАКАЗ

В блоке "Ваш заказ" показывать количество только выбранных брелков.

Если количество 0 — не показывать в заказе.

Пример:

Тип товара:
Готовые брелоки

Чёрный Бэтмен:
2 шт × 7 € = 14 €

Синяя акула:
1 шт × 7 € = 7 €

Итого:
21 €

━━━━━━━━━━━━━━━━━━━━

Для кастомного брелка:

Тип товара:
Кастомный брелок

Количество:
2 шт

Цена за 1 шт:
7 €

Итого:
14 €

━━━━━━━━━━━━━━━━━━━━

4. КНОПКА "СКОПИРОВАТЬ ЗАКАЗ"

Кнопка должна копировать количество и стоимость.

Пример:

Здравствуйте! Хочу заказать FORMIKA.

Тип товара:
Готовые брелоки

Чёрный Бэтмен:
2 шт × 7 € = 14 €

Синяя акула:
1 шт × 7 € = 7 €

Предварительная стоимость:
21 €

━━━━━━━━━━━━━━━━━━━━

5. ВАЖНО

Если во всех брелках количество 0, показывать подсказку:

Выберите количество брелков.

Не добавлять товары с количеством 0 в заказ.
